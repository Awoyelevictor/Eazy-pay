# **App Name**: FyreVTU

## Core Features:

- User Authentication & Profiles: Secure user sign-up and login through phone OTP, email, or social providers (Google/Apple), including management of user profiles with multi-level KYC.
- Real-Time Wallet Management: A dynamic wallet interface displaying real-time balance and transaction history with live updates.
- VTU Service Engine: Core functionality for purchasing virtual top-up services like airtime and data, with robust transaction processing to ensure atomicity and security.
- Integrated Payment Gateway: Seamless integration with local payment gateways (e.g., Paystack/Flutterwave) for users to fund their wallets securely.
- Dynamic User Dashboard: A mobile-first, responsive dashboard displaying a prominent real-time wallet balance, quick action buttons for services, and a summary of recent transactions.
- AI-Assisted UI Component Generation Tool: Utilize Firebase Studio's AI to generate specific UI components for features like the airtime purchase flow and transaction history based on natural language prompts.
- Push Notification System: Deliver real-time alerts and updates to users for successful transactions, balance changes, and promotional messages using Firebase Cloud Messaging.

## Style Guidelines:

- The visual scheme embraces a light aesthetic, chosen to foster trust and clarity essential for a financial service application. This provides a fresh and approachable user experience.
- Primary Color: A vibrant, clear green (#10B981) embodies growth, trust, and digital efficiency, aligning with the app's purpose of managing financial transactions. This hue offers a contemporary and professional feel.
- Background Color: A subtle, desaturated tint of green (#ECF2EF) ensures a clean and breathable canvas, providing high readability while harmonizing with the primary palette. Its lightness supports the overall fresh feel.
- Accent Color: A bright and lively lime green (#60E283) serves as the accent, strategically applied to calls-to-action, active elements, and notifications. This provides a dynamic contrast and directs user attention effectively.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly legible characteristics across various screen sizes. Its neutral design ensures an objective and professional tone suitable for a financial platform.
- Adopt a style of modern, minimalist line icons. Icons should feature slightly rounded edges to align with the fresh and friendly aspects of the green color palette, ensuring clarity and intuitiveness for navigation and features.
- Employ a mobile-first, responsive layout strategy. The design prioritizes clear content hierarchy, spacious elements for touch interaction, and an intuitive flow that adapts seamlessly to various device sizes, ensuring optimal user experience on the go.
- Incorporate subtle, functional animations for user feedback and state changes, such as transaction confirmations, button interactions, and data loading. These animations should be swift and understated, enhancing the user experience without causing distraction.
